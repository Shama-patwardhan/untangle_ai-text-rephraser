# Untangle

Untangle is an NLP-based writing analysis and controlled reconstruction system. The system analyzes writing for observable patterns commonly associated with AI-generated text, provides explanatory feedback on identified patterns, selectively reconstructs problematic passages, and verifies that meaning, factual claims, and authorial intent remain preserved.

Pipeline architecture:
```text
Analyze → Explain → Reconstruct → Verify → Re-analyze
```

> **Design & Ethical Principle:** Stylistic and statistical patterns measured by Untangle describe textual characteristics only. They do not constitute proof of authorship, and cannot determine whether a text was authored by a human or generated by an artificial intelligence.

### Phase 4 Scope & Robustness Guardrails
- **Contextual Sentence-Level Verification:** Rather than checking isolated token replacements in a vacuum, the preservation engine evaluates the surrounding sentence before and after applying candidate suggestions to verify numbers, citations, named entities, and polarity in actual syntax.
- **Syntactic & Grammatical Safeguards:**
  - **Arrangement Protection:** Prevents false-positive redundancy flags on *"in order to"* when *"in order"* denotes proper arrangement (e.g., *"must be in order to"*, *"keep files in order to"*).
  - **Prepositional Phrase Protection:** Distinguishes sentence-initial discourse transitions from prepositional phrases like *"In addition to [X]"*, preventing ungrammatical connective replacements.
  - **Gerund & Noun Phrase Compatibility:** Maps *"for the purpose of"* to direct prepositional *"for"* (e.g., *"for testing"* instead of ungrammatical *"to testing"*).
  - **Natural Punctuation on Metadiscourse:** Ensures phrase replacements like *"it is important to note that"* include natural comma punctuation (*"Notably, "*).
  - **Negative Verb Phrase Contractions:** Safely simplifies *"is not able to"* to *"cannot"*, keeping negative polarity intact.
- **Cadence & Structural Safety Guardrails:**
  - Sentence combination logic skips interrogative sentences ending with `?` and sentences with existing coordinating conjunctions (e.g., *"However"*, *"Therefore"*).
  - Preserves uppercase acronyms (`AWS`), proper names, and the pronoun `I` at the start of combined clauses (never lowercasing them into awkward tokens like `aWS`).
- **Enhanced Verification Engine (`app/services/verifier.py`):**
  - **Complex Numbers & Currency:** Verifies integers, decimals, thousands-separated numbers (`1,000,000`), and currency values (`$50,000`, `€1,200`).
  - **Comprehensive Academic Citations:** Supports multi-author and alphanumeric brackets (e.g., `(Smith & Jones, 2020)`, `[1, p. 5]`, `[Vaswani17]`).
  - **Sentence-Initial Proper Nouns:** Correctly identifies named entities and proper nouns even when positioned as the first word of a sentence (e.g., *"London"*, *"FastAPI"*).
  - **Negative Contractions:** Detects and verifies negative contractions (`doesn't`, `can't`, `won't`, `isn't`).
  - **Epistemic Certainty Tracking:** Alerts on both confidence inflation (hedging converted to high certainty) and requirement dilution (mandatory `must` converted to hedging `might`).
  - **Honest Multi-State Reporting:** Categorizes preservation into `verified`, `warnings_detected`, and `manual_review_required`, avoiding unsupported guarantees.

### Phase 3 Scope & Features
- **Reviewable Suggestions (No Silent Rewriting):** The system presents structured, reviewable improvement suggestions with alternatives and rationales rather than silently altering user text.
- **Identified Improvement Opportunities:**
  - **Redundancy Reduction:** Detects verbose filler and bureaucratic circumlocutions (e.g., *"in order to"* → *"to"*, *"due to the fact that"* → *"because"*, *"make a decision"* → *"decide"*) and suggests concise alternatives while preserving casing.
  - **Repetitive Transition Variation:** Suggests diverse discourse connectives or direct openings when sentence-initial transitions (e.g., *"Furthermore"*, *"Moreover"*) repeat.
  - **Repeated Phrase Tightening:** Flags verbatim multiword phrases repeated across passages, suggesting pronouns, concise referents, or synonym variation.
  - **Cadence & Monotonous Structure Improvement:** When uniform sentence lengths are detected, suggests combining adjacent short-to-medium sentences with coordinators or varying sentence openings to introduce natural rhythm.
- **Factual & Referential Preservation Verification:**
  - Every suggestion undergoes automated verification to confirm that numbers, percentages, currencies, academic citations, named entities, acronyms, and certainty polarity (negations/modals) remain intact.
- **Side-by-Side Preview Draft:** Generates an optional preview draft with non-conflicting improvements applied for comparison.



### Phase 2A Scope & Reliability Features
- **Deterministic Statistics Engine:**
  - Paragraph, sentence, word, and character counts.
  - Sentence segmentation with orphan symbol filtering (prevents ghost 0-word sentences from corrupting length metrics).
  - Sentence length metrics: arithmetic average, sample standard deviation (Bessel's correction with $N - 1$ degrees of freedom; $0.0$ for $\le 1$ sentences), and binned distribution.
  - Punctuation frequencies for ASCII and Unicode punctuation.
  - Repeated content words (filtering standard English stopwords).
  - Repeated multiword n-gram phrases (3–5 words) with sub-phrase subsumption and character offset spans.
- **Explainable Heuristic Pattern Detectors:**
  - `RULE_REPEATED_PHRASES`: Verbatim multiword phrases repeated at or above configurable threshold, with grammatical connective phrase protection (e.g., "in order to", "as well as" require $\ge 3$ occurrences to avoid false alarms).
  - `RULE_UNIFORM_SENTENCE_LENGTH`: Unusually low standard deviation in sentence lengths (labeled *experimental*), protected against short fragments by requiring substantive sentences ($\text{mean} \ge 5.0$ words, total $\ge 20$ words, or exact identical lengths).
  - `RULE_REPETITIVE_TRANSITIONS`: Repetitive sentence-initial discourse transitions (e.g., "Furthermore", "Moreover"), flagging consecutive occurrences or concentrated usage while ignoring distant occurrences across longer texts.
  - `RULE_FREQUENT_PUNCTUATION`: Elevated frequencies of specific punctuation marks (em-dashes, semicolons) relative to sentence count (labeled *experimental*), requiring $\ge 3$ occurrences and $\ge 3$ sentences to avoid false alarms on single parenthetical em-dash pairs.
- **Analysis Orchestration (`POST /api/v1/analyze`):**
  - Configurable maximum input length (default 20,000 characters).
  - Rejection of empty, whitespace-only, or oversized requests.
  - Neutral findings summary with explicit sample brevity caveats for short passages ($< 35$ words or $< 3$ sentences).
  - Mandatory authorship disclaimer included in every response.

### Known Limitations
1. **Rule-Based Sentence Segmentation:** Uses orthographic heuristics and a curated English abbreviation allowlist (`Dr.`, `Mr.`, `U.S.`, `p.m.`, `a.m.`, etc.). It may misclassify unconventional domain-specific abbreviations or sentences starting with lowercase tokens.
2. **Experimental Heuristics:** Rules for sentence-length uniformity and punctuation density are empirical heuristics and should not be treated as absolute indicators of machine-generated prose.
3. **No Authorship Attribution:** Statistical patterns describe observable text metrics only and cannot determine authorship or AI origin.

## 3. Backend Setup & Startup (FastAPI)

```powershell
# 1. Open the project root directory
Set-Location -Path "d:\Untangle"

# 2. Create virtual environment
python -m venv .venv

# 3. Activate virtual environment
.\.venv\Scripts\Activate.ps1

# 4. Install pinned dependencies
pip install -r requirements.txt

# 5. Copy example environment configuration
Copy-Item .env.example .env

# 6. Start the backend server
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

The backend API will be accessible at `http://127.0.0.1:8000`.

Default configuration in `.env.example`:
```dotenv
APP_NAME=Untangle
APP_VERSION=0.1.0
ENVIRONMENT=development
API_PREFIX=/api/v1
DEBUG=false

# Text Analysis Settings
MAX_TEXT_LENGTH=20000
MIN_REPEATED_PHRASE_WORDS=3
MIN_PHRASE_REPETITIONS=2
UNIFORM_SENTENCE_MIN_COUNT=3
UNIFORM_SENTENCE_STD_DEV_THRESHOLD=1.5
REPETITIVE_TRANSITION_MIN_COUNT=2
FREQUENT_PUNCTUATION_THRESHOLD=0.5
```
